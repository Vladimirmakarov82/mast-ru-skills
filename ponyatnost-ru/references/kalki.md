# Кальки с английского

Конструкции, где английская фраза переведена слово в слово. Слова русские,
смысл собрать невозможно.

| Калька | Откуда | Как писать |
|---|---|---|
| остается его ставка | publisher keeps their bid | владелец получает назначенную им цену целиком |
| берет на себя | takes on | делает, отвечает за, платит за |
| закрывает потребность | closes the need | решает задачу; написать какую |
| дает ценность | delivers value | приносит пользу; написать какую и кому |
| делает возможным | makes it possible | позволяет, дает |
| на регулярной основе | on a regular basis | регулярно, каждый месяц |
| в части чего-то | in terms of | о чем-то, по чему-то |
| работает на этот актив | works toward | помогает, укрепляет; написать как |
| второй поток дохода | second revenue stream | деньги приходят из двух источников |
| ложится в схему | fits the model | подходит, встает на место |
| под давлением | under pressure | теряет деньги, теряет клиентов; написать что именно |
| точка приложения силы | leverage point | место, где усилие дает больше всего |
| единая версия правды | single source of truth | все берут цифры из одного места |

## Проверка

Фраза читается вслух. Если так люди в разговоре не говорят, это калька.

Пример проверки: «у паблишера остается его ставка». В разговоре человек
скажет: «владелец сайта получает свою цену целиком». Первый вариант
живет только на бумаге.
