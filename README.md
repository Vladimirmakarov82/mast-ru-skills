# Пакет скиллов для русского текста Mast

Три скилла закрывают три разные болезни. Ставятся вместе.

| Скилл | Что лечит | Откуда |
|---|---|---|
| humanizer-ru | признаки машинного письма, вода, штампы | github.com/smixs/humanizer-ru, 114 звезд, MIT |
| nora-gal | канцелярит и кальки на уровне стиля | github.com/Halfofthesky/nora-gal |
| ponyatnost-ru | непонятность: жаргон без расшифровки, темные фразы | собран под Mast |

Первые два берут форму текста. Третий проверяет, доходит ли смысл до
читателя, который в теме не разбирается.

## Установка

```bash
npx skills add smixs/humanizer-ru -g
npx skills add Halfofthesky/nora-gal -g
```

Скилл ponyatnost-ru копируется руками:

```bash
cp -r ponyatnost-ru ~/.claude/skills/ponyatnost-ru
```

## Порядок работы над текстом

1. humanizer-ru убирает воду и машинные обороты
2. nora-gal лечит канцелярит
3. ponyatnost-ru гоняет линтер и слепого читателя

Текст уходит человеку, когда линтер чист и слепой читатель не нашел
темных мест.

## Что изменилось в правилах

Строка «tekst-check: X/10», которую автор ставил себе сам, отменяется.
Автор понятность своего текста оценивать права не имеет: он держит смысл
в голове и видит ясность там, где ее нет. Оценка приходит от слепого
читателя, который контекста лишен.
